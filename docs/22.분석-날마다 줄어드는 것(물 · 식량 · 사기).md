# 날마다 줄어드는 것 — 물 · 식량 · 사기 (KOUKAI2.EXE)

**아직 옮기지 않았다.** 셈은 다 읽었지만 비율 두 바이트의 새 게임 값이 이상해(아래) 굳히지 못했다.

## 날 넘김이 부르는 것 — 0x00417930 → 0x00417940 (바다에 있을 때만)

```
0x00417480   식량 (배마다)
0x004176F0   물   (배마다)
0x00417970 · 0x00417AD0 · 0x00417C40   (아직 안 봄 — 선원 · 병 · 수리로 보인다)
```

## 배 하나의 하루 — 0x00417570(식량) · 0x004177E0(물)

그 배에 그것이 없으면 다른 배(열 칸 가운데 있는 첫 배)에서 꺼낸다. 아무 배에도 없으면 `0x004176B0`.

```
먹는 양 = 선원 x 비율 / 100 + 1          (깃발 0x0045A1A8 & 0x1800 이면 / 200)
비율     = 식량 0x0045BDAA · 물 0x0045BDA9   (메뉴 0x00441800 이 올리고 내린다 — 「식량할당 · 급여설정」으로 보인다)
보급     = 칸 곁 30바이트 +2(식량) · +0(물) 에서 뺀다
사기     -= (100 - 선장 +0x1C / 2 - 비율) / 10     (괄호가 0 이하면 / 5 — 사기가 오른다)
사기는 칸 곁 +0x1C, 0~100 에서 자른다
```

## 떨어지면 — 0x004176B0

사기를 `min(16, 사기)` 만큼 깎고, 사기가 20 아래면 `0x00417650`(선상 반란으로 보인다).

## 비율의 새 게임 값

`0x00403703` 이 `0x0045BDA8 · A9 · AA` 세 바이트를 SDATA `0x48D6` 에서 옮긴다 — 값이 `FF FF 00` 이다. 세이브 열 칸도 같다.
`0x0045BDA8` 은 날 넘김(`0x004178EC`)이 1 씩 올리는데 세이브 값이 다 255 라 뜻이 맞지 않는다. 시나리오가 따로 매길 수도 있다.
