# 날마다 줄어드는 것 — 물 · 식량 · 사기 (KOUKAI2.EXE)

물 · 식량은 옮겼다(`PlayerState.ConsumeDay`). 사기는 셈만 읽었고 아직 옮기지 않았다(아래).

## 날 넘김이 부르는 것 — 0x00417930 → 0x00417940 (바다에 있을 때만)

```
0x00417480   식량 (배마다)
0x004176F0   물   (배마다)
0x00417970 · 0x00417AD0 · 0x00417C40   (아직 안 봄 — 선원 · 병 · 수리로 보인다)
```

## 배 하나의 하루 — 0x00417570(식량) · 0x004177E0(물)

그 배에 그것이 없으면 다른 배(열 칸 가운데 있는 첫 배)에서 꺼낸다. 아무 배에도 없으면 `0x004176B0`.

```
먹는 양 = 선원 x 비율 / 100 + 1          (깃발 0x0045A1A8 & 0x1800 — 상륙 「대기」(0x0041B1B0) 중 — 이면 / 200)
비율     = 식량 0x0045BDAA · 물 0x0045BDA9, 0~100 (메뉴 0x00441800 이 하나씩 올리고 내린다 — 「식량할당 · 급여설정」으로 보인다)
보급     = 칸 곁 30바이트 +2(식량) · +0(물) 에서 뺀다
괄호     = 100 − 선장 능력치 +0x1C / 5 − 비율
사기     -= 괄호 > 0 이면 괄호 / 5, 아니면 괄호 / 10 (음수라 오른다)
사기는 칸 곁 +0x1C, 0~100 에서 자른다. 20 아래면 0x00417650 — 선원이 min(선원, (20 − 사기) x 선원 / 100 + 1) 달아난다
```

식량 · 물 두 번 다 사기를 셈하므로 하루에 두 번 깎인다.

## 떨어지면 — 0x004176B0

사기를 `min(16, 사기)` 만큼 깎고, 사기가 20 아래면 `0x00417650`.

## 비율의 새 게임 값 — 고친다

예전에는 `0x00403703` 이 SDATA `0x48D6` 에서 옮긴다고 적고 값이 `FF FF 00` 이라 했는데 틀렸다.
옮겨 오는 버퍼 `0x0046A218` 은 함대 표 바로 뒤, SDATA 의 **`0x48D9`**(0x5D 바이트 — docs/23)다. 세 바이트 `0x0045BDA8 · A9 · AA` 는
새 게임에 **0 · 100 · 100** 이다 — 물 · 식량 모두 제 몫을 다 주고(배마다 하루 선원 + 1), 괄호가 `−능력치 / 5` 라 사기는 하루 `능력치 / 50` 씩 오른다.

`0x0045BDA8` 은 바다에 나온 날 수다. 날마다 1 씩 오르고 30 을 넘으면 쥐 떼(`0x00417970`), 60 을 넘으면 괴혈병(`0x00417AD0`)을 주사위로 굴린다.
다른 날 셈은 사기를 올리지 않는다. 사기는 옮겼다(`PlayerState.ConsumeDay`) — 처음 값은 60(빼앗은 배 채비 `0x0040B927`, 주점 셈도 60 으로 끌어당긴다). 달아나는 선원도 옮겼다.

## 쥐 떼 · 병 — `0x00417970` 쥐 떼 · `0x00417AD0` 괴혈병 (`PlayerState.DiseaseDay`)

예전에는 0x10 을 괴혈병, 0x20 을 열병으로 읽었다. 말(0x1D9 「쥐 떼가 발생하고 있는 모양입니다」 · 0x1DA 「괴혈병에 걸린 자가 있는」)과 아이템(쥐약이 0x10, 라임 주스가 0x20 을 지운다)으로 바로잡았다.

| 병 | 걸림 | 걸린 동안 날마다 |
|---|---|---|
| 쥐 떼(`0x0049F598` & 0x10) | 바다 날 수 > 30, 주사위(항해 레벨 / 5 + 2) == 0, 주사위(105) > 운(+0x23). 고양이(아이템 0x19)를 지니고 나가면 `0x0046EED4` 에 0x40 이 서서(`0x00435A5C`) 일지 않는다 | 배마다 식량 −min(식량, 10) |
| 괴혈병(& 0x20) | 바다 날 수 > 60, 주사위(105) > 운 | 배마다 선원 −min(선원, (100 − 선장 +0x1E) / 5 + 주사위(2)) |

항구에 들면 둘 다 낫고(`0x0041A588` 이 아래 여섯 비트를 지운다), 항에서 나가면 바다 날 수가 0 이 된다(`0x00422C36`).

## 바다 「급여설정」 — 목록 28 의 여섯째 (`0x00441B10` → `0x00441B50`)

동료를 고르면(`0x00439D50` 목록 0x89) 호감(+0x2B)이 80 이상일 때 0xDC 「그런 걱정은 안 해도 됩니다」 로 끝난다.
아니면 0xDD(주인공) · 0xDE(%s의 급료) 로 0 ~ 2000 을 묻고, 지금 급여(함대 뒤 덩이 +0x21 + 칸, x 10)보다 적으면 0xE0 「말도 안돼」 로 다시 묻는다.
받아들이면 0xDF, 호감 += (새 급여 − 지금) / 5(100 까지), 급여 칸에 새 급여 / 10 을 적는다.

## 출항 셈 — `0x004229A0`

항 「출항」(작은 항구의 「출항」도 같은 손)은 배마다 선원 · 보급을 늘어놓고, 선원 없는 배가 있으면 「이것으론 꼼짝도 못합니다.」(0x39)로 못 뜬다.
버틸 날 = min(물 합, 식량 합) / 선원 합(0 이면 1) — 0 이면 「이걸론 굶어 죽을 겁니다.」(0x3B)로 못 뜨고, 10 아래 0x3C, 10 ~ 180 은 「약 %d일 항해할 수 있습니다.」(0x3D),
180 넘으면 0x3A 로 물은 뒤 뜬다. 뜨면 항해일지에 (그 날 수, 항구)를 적는다(`0x00422C1F`).
