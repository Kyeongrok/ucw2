# SDATA.DAT 지도

새 게임 자료 `SDATA.DAT`(세이브 한 칸과 같은 꼴)는 `KOUKAI2.EXE 0x00403D20` 이 **fread 예순넷**으로 처음부터 차례로 읽는다.
읽는 크기를 차례로 더하면 함대 표까지는 파일 자리가 맞는다. 그 뒤는 손이 넘기는 크기가 버퍼 크기라 어긋나서
내용으로 맞췄다 — `0x4BDB` 는 배 기록 한가운데(「18」 「19」 이름이 기록 머리에 온다)이고, 함대 뒤 `0x48D9` 에서 선종(`0x4936`)까지가 꼭 0x5D 다.
파일은 0x8482 바이트다. 메모리는 읽어 넣는 곳이고, `0x0046xxxx` 는 읽은 뒤 제자리로 옮기는 버퍼다
(`0x004035C6` 이 주인공 표를, `0x00403316` 이 나라 표를 옮긴다).

| 파일 | 크기 | 메모리 | 것 |
|---|---|---|---|
| `0x0000` ~ `0x000A` | 1 · 2 | `0x0045A1E0` ~ `0x0045A1BC` | 머리 — 빠르기 · 해 · 달 · 날 · 시각 · 머문 항구(docs/17) |
| `0x000B` ~ `0x000E` | 1 x 4 | `0x0049F5A4` · `A0` · `9C` · `98` | 깃발 · 바람 · 해류 · 날씨 |
| `0x000F` ~ `0x001E` | 4 x 4 | `0x0045A1B8` · `B4` · `B0` · `AC` | 화면 자리 · 굴림 |
| `0x01C3` | 8 | `0x0049F3E0` | 시나리오 깃발 |
| `0x01CB` | 0x80 | `0x0049F360` | 시나리오 변수 |
| `0x024B` | 0x100 | `0x0049F260` | 시나리오 가리키개 |
| `0x07DD` | 0xE0 | `0x00465E10` → `0x0045E268` | **나라 표** 32 x 7 — +0x0A 서울 항구 |
| `0x0CAF` | 0x1770 | `0x004662E8` → `0x0045A240` | 사람 표 50 x 120 |
| `0x241F` | 8 | `0x00467A58` | 돈(dword) · 은행 잔고(낱말 x 100 + 바이트) · 주인공 번호 — 새 게임은 모두 0 |
| `0x2427` | 0x54 | `0x00467A60` → `0x0045A1E8` | **주인공 표** 14 x 6 — +6 ~ +0x0C 일곱이 100, +0x0D 작위 |
| `0x247B` | 0x245E | `0x00467AB8` | 함대 0x85 x 70 (docs/19) — 손이 넘기는 0x2760 은 버퍼 크기(0x90 x 70, `0x004036F2` 가 0x90 씩 민다)다 |
| `0x48D9` | 0x5D | `0x0046A218` → `0x0045BDA8` | 바다에 나온 날 수 · 물 비율 100 · 식량 비율 100, 그 뒤 표 둘(`0x0045BDAB` · …) |
| `0x4936` | 0x12C | `0x0046A278` | 선종 12 x 25 |
| `0x4A62` | 0x596 | `0x0046A3A8` | 배 기록 22 x 65 |
| `0x55B6` | 0x7D0 | `0x004608E0` | 아이템 20 x 100(docs/24) |
| `0x5D86` | 0x2BC | `0x00460620` | 발견물 7 x 100(docs/26) |
| `0x4FF8` ~ | | | 교역품 · 시장(`0x605A`) · 항구 형편(`0x66DA`)(docs/20) |
| `0x8462` | 1 | `0x0049F9C8` | 끝 |

새 게임의 돈이 0 인 것은 첫 돈을 시나리오가 주기 때문이다(docs/21). 나라 표의 서울은 리스본 · 세빌리아 · 2 · 29 · 8 · 33 · 4 로
주인공들의 고향과 맞는다. 주인공 나라는 사람 표 +0x31 의 아래 네 비트(조안 0 · 카탈리나 1 · 알 2 · 옷토 3 · 피에트로 4 · 에르네스트 5)다.

나라 표 한 줄(32바이트) 가운데 +0x0B ~ +0x11 일곱은 나라 사이 사이(제 나라 100)로 보인다.
