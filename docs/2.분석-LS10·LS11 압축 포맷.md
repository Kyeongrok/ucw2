# LS10 / LS11 압축 — 껍데기와 알맹이를 다 옮겼다

대상: `대항해시대2` 의 `.LZW` 파일들. 정적 분석은 Win95판 `KOUKAI2.EXE`(32비트 PE, base `0x400000`).

한 줄 답: **엘리아스 감마꼴 부호로 심볼을 읽는 LZ77 이다.** 심볼이 256보다 작으면 글자표를
짚고, 크면 `심볼-256` 칸 뒤를 돌아본다. 길이는 뒤따르는 심볼 + 3 이다.

`.LZW` 라고 이름 붙었지만 **LZW 가 아니다.** 사전을 키우지 않는다.

## 껍데기

| 자리 | 크기 | 것 |
|---|---:|---|
| `0x000` | 4 | 매직 `"LS10"` 또는 `"LS11"` (짜임은 같다) |
| `0x004` | 12 | 0 으로 채움 |
| `0x010` | 256 | **글자표** — 0~255 가 한 번씩 든 순열, 빈도순 |
| `0x110` | 12N | 청크 목록 |
| | 4 | 0 으로 끝맺음 |
| 그 뒤 | | 압축 청크들 |

청크 하나는 **빅엔디안 32비트 셋**이다. 16비트 DOS 프로그램인데도 빅엔디안이다.

```c
struct LsEntry { uint32_be packedSize, unpackedSize, fileOffset; };
```

**청크 수는 세지 않고 셈한다**(`0x0041C109`).

```
count = (첫 청크의 fileOffset - 0x110) / 12      // 내림. 끝맺음 4바이트가 나머지로 떨어진다
```

`packedSize == unpackedSize` 면 **안 눌린 것이라 그대로 읽는다**(`0x0041C3F9` 의 `cmp esi,edi`).
`PORTCHIP.LZW` 의 4바이트짜리 청크 일곱 개가 그 경우다.

## 알맹이

### 심볼 하나 (`0x0041C240`)

```
k = 0
do { b = 비트 1개; k++ } while (b == 1)     // 0 이 나올 때까지 센다
symbol = (1 << k) - 2 + 비트 k개
```

비트는 **MSB 먼저**다(`0x0041C1B0`). 곧 부호 길이는 `2k` 비트고 담는 값은 이렇다.

| k | 부호 길이 | 심볼 범위 |
|---:|---:|---|
| 1 | 2 | 0 ~ 1 |
| 2 | 4 | 2 ~ 5 |
| 3 | 6 | 6 ~ 13 |
| 4 | 8 | 14 ~ 29 |
| 5 | 10 | 30 ~ 61 |
| 6 | 12 | 62 ~ 125 |
| 7 | 14 | 126 ~ 253 |
| 8 | 16 | 254 ~ 509 |
| 9 | 18 | 510 ~ 1021 |
| … | | |

**흔한 글자는 두 비트, 드문 글자는 열여섯 비트다.** 그래서 파일마다 빈도순 글자표를
새로 계산해 머리에 박아 둔다 — 모드판의 표가 원판과 129곳 다른 것이 그 증거다.

### 푸는 고리 (`0x0041C290`)

```
남은 = unpackedSize
while 남은:
    s = 심볼()
    if s < 256:
        내놓기( 글자표[s] );  남은 -= 1
    else:
        n = 심볼() + 3
        거리 = s - 256
        내놓은 것의 끝에서 거리만큼 앞을 한 바이트씩 n 개 베낀다   # 겹쳐도 된다
        남은 -= n
```

베끼기가 **한 바이트씩**이라 `거리 < 길이` 인 겹침이 되풀이 무늬를 만든다. 바다처럼
같은 값이 이어지는 데서 이것이 많이 나온다.

## 검산

원판 · Win95 이식판 · 어전편 모드 · 교정판 모드의 `.LZW` **서른한 개가 모두** 풀리고,
청크마다 적힌 `unpackedSize` 와 낸 길이가 딱 맞는다.

|---|---:|---|---|

| `PORTMAP.LZW` | 101 | 9,216 (=96x96) | 항구지도 |
| `PORTCHIP.LZW` | 14 | 30,720 x7, 4 x7 | 칩 일곱 벌 x 240장 |
| `DATA1.LZW` | 19 | 32,768 등 | 11번이 세계 칩 256장 |
| `KAO.LZW` | 256 | 1,920 x128, 864 x128 | 얼굴 128명 |
| `CHAR.LZW` | 7 | 5,120 x6, 15,360 | 사람 그림 |
| `IAP1~6.LZW` | 35 | | |
