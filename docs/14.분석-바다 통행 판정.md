# 바다 통행 판정 (KOUKAI2.EXE)

옮긴 자리: `Uw2.Support/Local/Formats/ChipMap.cs`(`CanSail`) · `Uw2.Game/Engine/Sea/Fleet.cs`(`CanSail`).

## 0x00448310(x, y) — 1 이면 막힘

함대 둘레의 칩 창(가로 96 칩, `0x0046EED8`)을 짚는다. 창의 왼위는 `0x0049EFB0` · `0x0049EFB4` 다.

```
i = (y - 창y) * 96 + (x % 720 - 창x)
담개[i], 담개[i+1], 담개[i+96], 담개[i+97]  넷이 다 0x34 아래면 간다
```

곧 **함대는 칩 2 x 2 를 차지**하고 넷이 다 바다여야 한다.

## 담개에 든 값 — 0x0041DE78

칸 값을 칩으로 펴서 담개에 넣을 때 이미 눌러 둔다.

| 칸 값 | 넣는 칩 |
|---|---|
| 0x10 아래 | 네 비트가 2 x 2 자국 — 켜진 칸은 `0x41`(뭍), 꺼진 칸은 0 |
| 그 위 | 그림표의 칩. **`0x34` 아래면 0** 으로 눌러 넣는다 |

그래서 담개 값은 `0` · `0x41` · `0x34 이상` 셋뿐이고, 판정 `< 0x34` 는 **칩 0 만 지난다**는 뜻이다.
해안 칩(`0x34` 이상 — 물가가 반쯤 그려진 칩)은 **모두 막힌다.**

예전 기록이 「해안 칩을 지날 수 있는지 안 갈렸다」고 했던 것은 이것으로 닫는다. 바뀐 것은 판정이
**한 칩이 아니라 2 x 2** 라는 점 — 배가 뭍에 반 칸 더 떨어져 선다.
