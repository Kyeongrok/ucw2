# 교역소 — 시장과 값 (KOUKAI2.EXE)

옮긴 자리: `Uw2.Support/Local/Formats/Economy.cs` · 고르기 `SeaMapWindow.Trade`.

**판 주의**: `KOUKAI2.EXE` 는 일본어판(글이 SJIS)이고 `KOUKAI2-han8.exe` 가 한글판이다. 코드 주소는 일본어판 기준이다.
교역품 이름은 한글판 파일 `0x550F0` 에서 11바이트씩(일본어판 메모리 `0x00456EF0`, `이름 = 0x456EF0 + 번호 x 11`).

## 교역품 46 · 갈래 10

갈래 경계 `0x004570F0` = `06 0A 11 15 1A 1F 21 24 28 2E` — `0x004202E0` 은 경계가 교역품 번호보다 큰 첫 차례를 돌려준다.

| 갈래 | 번호 | 교역품 |
|---|---|---|
| 향신료 | 0~5 | 정향 계피 후추 육두구 피망 생강 |
| 기호품 | 6~9 | 담배 차 커피 카카오 |
| 식품 | 10~16 | 설탕 유제품 어육 곡류 올리브유 와인 돌소금 |
| 섬유 | 17~20 | 생사 무명 양모 마 |
| 직물 | 21~25 | 면직물 견직물 모직물 벨벳 삼베 |
| 보석 | 26~30 | 산호 호박 상아 진주 구갑 |
| 귀금속 | 31~32 | 금 은 |
| 광석 | 33~35 | 동 주석 철광석 |
| 사치품 | 36~39 | 미술품 융단 사향 향수 |
| 기타 | 40~45 | 유리구슬 염료 도자기 유리그릇 무기 목재 |

## 시장 — SDATA.DAT 0x605A, 128바이트 x 13 (메모리 0x0045FF88)

| 자리 | 것 |
|---|---|
| +0x00 | 낱말 x 46 — 이 시장이 교역품마다 쳐 주는 값(팔 때) |
| +0x5C | 낱말 x 9 — 파는 교역품의 바탕 값 |
| +0x6E | 바이트 x 9 — 파는 교역품(0xFF 빈 칸) |
| +0x77 | 바이트 x 9 — 그 교역품이 나오는 경제(항구 경제 ≥ 이것 x 10, `0x004204DF`) |

시장 0(리스본 · 세빌리아 · 바르셀로나 · 발렌시아): 유제품 30 · 어육 20 · 올리브유 28 · 와인 36 · 면직물 70 · 벨벳 80 · 삼베 50 ·
염료 120 · 무기 120. 정향을 140, 계피를 120, 후추를 80 에 사 준다.

## 항구 형편 — SDATA.DAT 0x66DA, 37바이트 x 100 (메모리 0x0045F110, 0x0043AEF0)

| 자리 | 것 |
|---|---|
| +0x00 | 경제(낱말) — 리스본 780 |
| +0x04 | 공업(낱말) |
| +0x08 | 나라 몫 여섯(리스본은 포르투갈 100) |
| +0x0E | 갈래 값 지수 열(50 언저리) |
| +0x18 | 특산품 바탕 값(낱말) |
| +0x1A | 특산품(0xFF 없음) — 리스본 돌소금 |
| +0x21 | 시장 번호 |

## 사는 값 — 0x004208D0

```
값 = 바탕 x (갈래 지수 + 50) / 100
허가증이 없으면 x 12 / 10      (0x00420430 — 그 항구 나라의 소지품 0x23 + 나라 가 있으면 x 10/10)
```

리스본 유제품: 30 x (52 + 50) / 100 = 30 → x 1.2 = **36**.

## 남은 것

- 파는 값(`매각`, `0x00420E30` 언저리)과 사고팔기 · 짐칸.
- 특산품이 늘 나오는지 — 목록을 짓는 손(`0x004204A0`)이 어떤 깃발(`ebp`)일 때만 붙인다. 지금은 늘 붙인다.
- 갈래 지수가 사고팔 때 오르내리는 셈, 투자.
