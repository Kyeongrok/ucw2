# 교역소 — 시장과 값 (KOUKAI2.EXE)

옮긴 자리: `Uw2.Support/Local/Formats/Economy.cs` · 고르기 `SeaMapWindow.Trade`.

**판 주의**: `KOUKAI2.EXE` 는 일본어판(글이 SJIS)이고 `KOUKAI2-han8.exe` 가 한글판이다. 코드 주소는 일본어판 기준이다.
교역품 이름은 한글판 파일 `0x550F0` 에서 11바이트씩(일본어판 메모리 `0x00456EF0`, `이름 = 0x456EF0 + 번호 x 11`).

## 교역품 46 · 갈래 10

갈래 경계 `0x004570F0` = `06 0A 11 15 1A 1F 21 24 28 2E` — `0x004202E0` 은 경계가 교역품 번호보다 큰 첫 차례를 돌려준다.

| 갈래 | 번호 | 교역품 |
|---|---|---|
| 향신료 | 0~5 | 정향 계피 후추 육두구 피망 생강 |
| 기호품 | 6~9 | 담배 차 커피 카카오 |
| 식품 | 10~16 | 설탕 유제품 어육 곡류 올리브유 와인 돌소금 |
| 섬유 | 17~20 | 생사 무명 양모 마 |
| 직물 | 21~25 | 면직물 견직물 모직물 벨벳 삼베 |
| 보석 | 26~30 | 산호 호박 상아 진주 구갑 |
| 귀금속 | 31~32 | 금 은 |
| 광석 | 33~35 | 동 주석 철광석 |
| 사치품 | 36~39 | 미술품 융단 사향 향수 |
| 기타 | 40~45 | 유리구슬 염료 도자기 유리그릇 무기 목재 |

## 시장 — SDATA.DAT 0x605A, 128바이트 x 13 (메모리 0x0045FF88)

| 자리 | 것 |
|---|---|
| +0x00 | 낱말 x 46 — 이 시장이 교역품마다 쳐 주는 값(팔 때) |
| +0x5C | 낱말 x 9 — 파는 교역품의 바탕 값 |
| +0x6E | 바이트 x 9 — 파는 교역품(0xFF 빈 칸) |
| +0x77 | 바이트 x 9 — 그 교역품이 나오는 경제(항구 경제 ≥ 이것 x 10, `0x004204DF`) |

시장 0(리스본 · 세빌리아 · 바르셀로나 · 발렌시아): 유제품 30 · 어육 20 · 올리브유 28 · 와인 36 · 면직물 70 · 벨벳 80 · 삼베 50 ·
염료 120 · 무기 120. 정향을 140, 계피를 120, 후추를 80 에 사 준다.

| 자리 | 것 |
|---|---|

## 사는 값 — 0x004208D0

```
값 = 바탕 x (갈래 지수 + 50) / 100
허가증이 없으면 x 12 / 10      (0x00420430 — 그 항구 나라의 소지품 0x23 + 나라 가 있으면 x 10/10)
```

리스본 유제품: 30 x (52 + 50) / 100 = 30 → x 1.2 = **36**.

## 남은 것

- ~~파는 값~~ — `0x004210E0`: 쳐 주는 값 x (지수 + 50) / 100, 특산품이면 바탕 x (지수 + 50) / 200. 리스본 정향 138.
- ~~사고팔기 · 짐칸~~ — `PlayerState`: 돈(`0x0049F5A8`), 배마다 보급 넷 · 교역품 다섯 칸(칸 곁 30바이트 +0 · +0x0C · +0x16), 실을 자리는 배 기록 +0x14. 첫 돈은 시나리오 어림(docs/21).
- 특산품이 늘 나오는지 — 목록을 짓는 손(`0x004204A0`)이 어떤 깃발(`ebp`)일 때만 붙인다. 지금은 늘 붙인다.
- 갈래 지수가 사고팔 때 오르내리는 셈, 투자.

## 조선소 — 지을 수 있는 배

항구 형편 `+0x22` 가 **조선소 갈래**, `+0x23` 이 짓고 있는 배(0xFF 없음)다. 갈래마다 선종 줄이 `0x00458BD0`(8바이트 x 11)에 있다.

| 갈래 | 항구(맛보기) | 선종 |
|---|---|---|
| 0 | 리스본 · 세빌리아 | 발사 · 경갤리 · 카라벨 라티나 · 브리간틴 · 플랜더스 갤리 · 나오 · 카락 · 갤리온 |
| 1 | 런던 | 카라벨 레돈다 · 나오 · 카락 · 갤리온 · 슬루프 · 프리게이트 · 바그 |
| 2 | 암스테르담 · 함부르크 | 한 자 콕 · 카라벨 라티나 · 나오 · 카락 · 갤리온 · 프리게이트 · 쉽 |
| 4 | 제노바 | 경갤리 · 타렛테 · 카라벨 라티나 · 버스 · 플랜더스 갤리 · 나오 · 베네치안 갤리 · 카락 |
| 5 | 이스탄불 | 경갤리 · 카라벨 라티나 · 플랜더스 갤리 · 나오 · 지벡 · 베네치안 갤리 · 카락 |
| 9 | 나가사키 | 관선 · 안택선 · 철갑선 |
| 10 | 카라카스 | 브리간틴 · 피네스 · 나오 · 카락 · 갤리온 |

「함선 건조」(`0x00428930`)는 줄 첫 선종의 `+0`(= 드는 공업 / 10) x 10 이 항구 공업(`+4`)보다 크면 「못 짓는다」(말 0xFB)로 끝낸다.
선종 표 `+0` 의 뜻이 이것으로 굳었다 — **드는 공업 / 10**. 우리는 줄마다 같은 셈으로 거른다(리스본 공업 770 이면 갤리온(800)은 빠진다).
값은 선종 `+10`. 짓기(날 수 · 돈)는 아직이다.

## 항 「보급」 — 0x00422CF0 · 0x00422E80

배마다 물 · 식량 · 자재 · 탄약을 싣는다(`0x00422E80(배, 갈래)` 싣기, `0x00423020` 내리기). 한 단이 **열 통**이다
(`add word [제 함대 칸 곁 + 갈래 x 2], 단 x 10`). 실을 수 있는 만큼 = 배의 짐 자리(+0x14) - 지금 짐(`0x0043B000`), 돈으로도 자른다. 짐은 물 / 10 + 식량 / 10 + 자재 + 탄약 + 교역품이다 — 물 · 식량 열 통이 짐 하나. 빠르기 셈의 짐(칸 곁 +0x0A)은 여기에 대포 문 x 한 문 무게(`0x00457258`) / 10 과 선원을 더한 배 무게(`0x0043B0A0`)다.

| 갈래 | 값(한 단) | 리스본 |
|---|---|---|
| 물 | 공짜(말 0x3E) | 0 |
| 식량 | (식품 지수 + 50) x 20 / 100 | 20 |
| 자재 | (기타 지수 + 50) x 18 / 100 | 18 |
| 탄약 | (식품 지수 + 50) x 120 / 100 — 원본도 식품 바이트 `+0x10` 을 쓴다 | 122 |

## 값 깎기 (`0x00420850` → `0x00420B70`)

교역품을 고르면 0x96(%s 시세는 금화 %d닢입니다. 좋습니까？)을 묻고, 아니오면 값을 깎는다. P 는 한 통 값(`0x004208D0`)이다.

```
바닥   = P x (19 − 작위) / 20        작위는 제 나라 항구에서만 친다(남의 나라는 19/20)
받는 값 = P − (P − 바닥) / 2          부른 값이 이 이상이면 0xA 「그 값에 타협합시다」
틈     = 받는 값 − 바닥               1 이하면 0xB 「더이상 값을 깎지 말아 주세요」
되부름  = max(바닥, P − 틈 / 2)        0xC 「금화 %d닢에 사주세요」
```
주인공이 사람 +0x30 의 1 을 지녔거나 경리주임(처지 4, `0x0043AF90(4)`)이 회계(+0x30 의 2)를 지녔으면 되부름 뒤
0x353 「금화 %u닢이라면…」 · 0x354 「좋아요, 금화 %u닢으로 타협합시다」 로 바닥 값에 산다.
