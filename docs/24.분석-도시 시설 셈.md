# 도시 시설 셈

건물 고르기(`MENU.DAT`) 다음에 부르는 손들이다. 손표는 주점 `0x00458AC8`, 조선소 `0x00458CB0`, 은행 `0x00458638`, 교역소 `0x004217B0` 의 표다.

## 주점 「선원 고용」 — `0x004241B0` (`Pub`)

| 것 | 셈 |
|---|---|
| 빈 자리 | 배마다 배 기록 +0x12(선원 자리) − 함대 칸 +0 선원. 없으면 말 0x1D |
| 돈 | 10 아래면 말 0x1E |
| 매력 몫 S | 주인공 능력치 +0x22 / 3 (`0x00426CAD`). 30 아래면 한 번 더 묻는다(말 0x1F · 0x20) |
| 올 사람 | min(경제 x S / 500, (작위 + 1) x S) — 경제는 항구 형편 +0, 작위는 주인공 표 +0x0D |
| 한 사람 값 | 경제 / 20 + 5 |
| 쓸 수 있는 수 | min(올 사람, 돈 / 값, 빈 자리 합) |

고용한 뒤 배마다 몇 명을 태울지 고르고(`0x00424540`), 새 선원만큼 사기를 60 쪽으로 끌어당긴다 —
`사기 = 60 + (사기 − 60) x 전 선원 / 새 선원`. 우리는 앞 배부터 채우고 사기는 아직 셈하지 않는다.
새로 지은 배는 선원 0 · 보급 0 · 내구 = 최대 내구 = 선종 내구 x 9 / 10 으로 온다(`0x0043DF3A`).

## 은행 — `0x0041E410` 예금 · `0x0041E540` 출금 · `0x0041E640` 대출 · `0x0041E780` 상환 (`Bank`)

통장은 부호 있는 잔고 하나(`0x0049F5AC` 낱말 x 100 + `0x0049F5AE` 바이트)다.

| 것 | 셈 |
|---|---|
| 예금 | 돈이 1000 을 넘어야 한다(말 0x64), 빚이 있으면 안 된다(0x66). min(돈, 1,000,000 − 잔고) |
| 출금 | 예금이 있어야 한다(0x68). 돈이 6억을 넘지 않게(0x6D) |
| 대출 | 예금이 없어야 한다(0x6F). 1000 + 10000 x 작위² + 잔고 까지(다 썼으면 0x71). 돈이 100만 넘으면 말 0x70 |
| 상환 | 빚이 있어야 한다(0x76). min(빚, 돈) |
| 이자 | 달이 바뀔 때(`0x0043AA52 → 0x0042B720 → 0x0042B800`) 예금 3% · 빚 10%, ±1,000,000 에서 자른다 |

## 조선소 — `0x00429C30` 수리 · `0x00429D60` 매각 (`Shipyard`)

| 것 | 셈 |
|---|---|
| 수리 값 | 20 x ((선종 역풍 − 함대 칸 +4) + (선종 돛 − +5) + (+3 최대 내구 − +2 내구)). 0 이면 말 0xCC |
| 고친 뒤 | 내구 = 최대 내구, 역풍 · 돛 = 선종 값. 최대 내구는 그대로 |
| 배 값 | ((등급 x 값 / 10 + 4 x 값 / 5) x (값 지수 열 평균 + 50) / 100) 을 10 에서 자름(`0x00429040`). 등급은 배 기록 +0x10 & 7 |
| 매각 | 배 값 / 2. 한 척뿐이면 말 0xD0. 짐(0xD3) · 선원(0xD4)이 있으면 한 번 더 묻는다 |

## 투자 — `0x004212B0` 교역소 · `0x0042A850` 조선소 공업

| 것 | 셈 |
|---|---|
| 막는 곳 | 나라 서울(`0x00431A70`, 나라 표 +0x0A 를 앞 여섯 나라만) — 말 2 |
| 한도 | 이달 투자(항구 형편 +2 경제 몫 · +6 공업 몫)가 50000 이면 말 7. min(돈, 50000, 50000 − 이달 투자) |
| 나라 몫 | 오름 = min(투자 / 경제(공업투자면 공업), 100 − 우리 몫). 몫 있는 다른 나라들이 똑같이 나눠 내고 모자란 것은 하나씩 더 낸다(`0x0042A5D0`) |

## 달마다 — `0x0042B720`

1. `0x0042B750` — 달 % 6 == 2 면 바람 장을 다시 읽는다.
2. `0x0042B800` — 은행 이자.
3. `0x0042B8A0` — 항구 형편 백: 경제 += 이달 투자 / 300, 공업 += 공업 투자 / 300 (1000 까지), 투자는 0 으로. 값 지수 열은 저마다 1~5 씩 50 쪽으로.
4. `0x0042B960` — 나라 · 바다 갈래 경제 합(아직).
5. `0x0042C170` — 떠돌이 항해자 옮김(`0x0042C190`), 맞수 주인공 레벨 따라잡기(`0x0042C240`, 아직), 맞수 함대(`0x0042C330`, 아직), 동료 급여(`0x0042C4E0`).

## 주점 「항해자와 대화」 — `0x00425890` (`Navigators`)

목록 12(한턱내기 · 항해자정보 · 고용 · 결투), 손표 `0x00458A90`.

| 것 | 셈 |
|---|---|
| 주점에 있는 이 | 주인공이 아니고 사람 +0x31 & 0x20(항해자), +0x2D 가 이 항구이거나 우리 함대에 탄 이, 그 가운데 +0x2F & 0x10 (`0x0043CB10 · 0x0043CBB0`) |
| 여관에 있는 이 | 같은 이 가운데 +0x2F & 0x10 이 아닌 이(`0x0043CC20`). 여관 목록 4 의 손표 `0x004586F0`, 그 아래는 정보 · 고용 둘(`0x004586E8`) |
| 한턱내기 | 값 = 표 `0x004571E8`[항구 형편 +0x24] (1~6). 호감 +0x2B += 6 x (+0x2F 아래 두 비트가 주인공과 같으면 3, 아니면 1) x (+0x2F & 0x40 이면 2) |
| 고용 막힘 | +0x2E ≠ 0(말 0x31), 동료 칸 서른이 다 참(0x8C), 호감 30 이하(0x8D) |
| 고용 겨룸 | 그 이의 가장 높은 능력치 k. 우리 = (레벨 둘 합) x 능력치[k], 여기에 작위 / 10 몫을 더함. 우리 > 주사위(20) + (그 이 레벨 합) x 능력치[k] 이면 받아 준다(아니면 0x91) |
| 급여 | min(20, 그 이 몫 / 400 + 주사위(3) + 1) x 10 — 물어 보고(0x8E) 받으면 |
| 들어오면 | +0x2D = 0xFF, +0x2C = 우리 함대, +0x2E = 6, 호감 += 10. 동료 칸 `0x0045BDAB`(서른)에 번호, `0x0045BDC9` 에 급여 / 10 |

새 게임에는 사람 79 ~ 119 가 항구마다 흩어져 있다. +0x2F 위 네 비트는 성격(`0x0042AFEC` 가 주사위 16 으로 만든다)이라
0x10 이 선 이는 주점에서, 아닌 이는 여관에서 만난다 — 리스본은 둘 다 여관(85 · 96)이다. 여관 고용은 `0x00425590(0)` 이라 호감을 보지 않는다.
달마다 떠돌이 항해자(함대에 안 타고 머무는 항구가 있는 이)는 1/3 로 항구 번호가 주사위(5) − 2 만큼 옮겨 간다(0~96, `0x0042C190`).
조선소에서 배를 짓거나 사려면 원본은 처지(+0x2E)가 3 이상인 동료가 있어야 한다(`0x00429180`) — 아직 막지 않는다.

## 동료 급여 — `0x0042C4E0` (달마다, `Navigators.PayWages`)

급여 합 = 동료 칸마다 급여 / 10 을 더해 x 10. 돈이 모자라면 내지 않고 동료마다 사람 +0x31 에 0x80 을 세운다(말 0x23C), 아니면 낸다(0x23E).
그다음 호감이 100 이 아닌 동료마다 `호감 = 호감 + 주인공 +0x1C + 급여 / 10 x 2 − 그 이의 +0x1C ~ +0x23 가운데 가장 큰 것`(0~100).

## 교회 — `0x004217D0` 예배 · `0x00421830` 기부 (`Church`)

| 것 | 셈 |
|---|---|
| 예배 | 들어온 뒤 처음이면(`0x0049A188`) 주인공 사람 +0x23(운) += 주사위(2), 100 까지 |
| 기부 | 몫 = 돈 / 낸 돈. 몫 > 10 이면 받기만 한다(말 0x5E). 아니면(0x5F) 낸 돈 ≥ (주사위(5) + 1) x 100 일 때 운 += 11 − 몫 |

## ITEM 가게 — `0x0041FE80` 구입 · `0x00420060` 매각 (`ItemShop`)

아이템 표는 SDATA `0x55B6`, 20바이트 x 100(메모리 `0x004608E0`). +0 이름 · +0x10 값 / 100 · +0x12 힘 · +0x13 갈래(아래 네 비트: 0 ~ 3 칼 · 6 갑옷 · 7 항해 기구 · 8 잡것 · 9 쓰는 것 · A 선물 · B 보석 · C 지도 · D 보물, 0x10 은 못 판다).
가진 것은 `0x0045BDE7` 스물(표 6 +0x3F) — 시나리오가 가장 많이 짚는 자리다.

| 것 | 셈 |
|---|---|
| 파는 것 | 항구 형편 +0x1D 부터 셋. 하루 안 시각 6 ~ 8 이면 넷째(+0x20)까지(`0x0043CE70`) |
| 구입 | 값 x 100. 갈래 7 아래(칼 · 갑옷)는 같은 것을 또 못 산다(말 0x14C) |
| 매각 | 값 / 2 x 100. 힘 0 이면 안 받는다(0x3A1). 마다하면 주사위(100) ≤ 운(+0x23)일 때 매력(+0x22)% 올려 다시 부르고, 아니면 끝 |

## 왕궁 — `0x00427E60` (`Palace`)

목록 16(알현 · 망명 · 자금원조 · 선박원조 · 밀회), 손표 `0x00427F36`. 그 항구 나라는 항구 표 +0x15 & 7(docs/10).
주인공 나라(사람 +0x31 & 7)와 다르면 목록을 막는다(`0x00427EB4`) — 망명은 그때 쓴다.

| 것 | 셈 |
|---|---|
| 자금원조 | 나라 표 +5 x 1000 을 돈에, +5 = 0(`0x00427A60`). 0 이면 말 0x1CD. 시나리오가 +5 를 세운다 |
| 선박원조 | 나라 표 +8 이 남은 척수, +7 이 선종. 함대 자리 · 맡을 동료가 있어야 하고 한 척에 +8 을 하나 줄인다(`0x00427B20`) |
| 망명 | 주인공 +0x31 아래 세 비트 = 그 나라, 고향 항구 = 이 항구. 새 나라 표 +2 가 7 이면 6, +5 ~ +7 = 0. 주인공 표 +6 + 나라(호의): 옛 나라 30 이상이면 −30, 새 나라 +10(100 ~ 200)(`0x00427910`) |

## 조합 「업무 알선」 — 함께 쓰는 시나리오 SNR0 (`0x0041E900`)

일은 손이 아니라 **SNR0 시나리오**가 돌린다. SNR0 는 주인공 시나리오보다 먼저 건물마다 도는 둘째 기계(`0x0043F8C0` → `0x0043F830`)로
깃발 `0x0049F3E0` · 변수 `0x0049F360` · 가리키개 `0x0049F260` · 장 `0x0049F3EC` · 절 `0x0049F3E8` 을 따로 쓴다.

| 장 | 방아쇠 | 뜻 |
|---|---|---|
| 0 | 아무 항구 조합(6) · 왕궁(5) · 모든 건물 | 일 없음 — 조합에 들면 고를 일 셋(변수 0 ~ 2 갈래, 3 ~ 5 짝)을 마련한다 |
| 1 | 아무 항구 교역소(0) | 상품 수송 — 변수 16 실을 곳, 17 내릴 곳 |
| 2 | 아무 항구 교역소 | 상품 구입 |
| 3 | 아무 항구 조합 | 편지 배달 |
| 4 | 항구 0xA1 · 0xA2 갈래, 조합 | 해적 퇴치 |
| 5 | 항구 13 은행 | 빚 수금 |
| 6 ~ 8 | 왕궁 | 나라 일(시나리오 몫) |

「업무 알선」은 장 0 일 때 변수 0 ~ 2 의 일 이름(`0x00458688` 부터 — 상품수송 · 상품구입 · 편지배달 · 해적퇴치 · 빚수금)을 늘어놓고,
고르면 변수 8 = 짝, 절 = 차례 + 1 로 조합 이벤트를 돌린 뒤 장 = 변수 6(`0x0041EA61`). 일을 마치거나 그만두면 이벤트가 F1 을 밟는데,
SNR0 에서는 장이 바뀌면 장 · 절을 0 으로 돌린다(`0x0043F889`). 깃발 16 · 17 이 다 서 있으면 조합이 일을 주지 않는다(말 0x19A + 나라).

수송 한 판(테스트): 리스본 조합 → 튀니스 교역소 「피사항에 정향를 60정도 1개월 이내에 날라 주시오 · 보수는 금화 1000닢」(E2 로 싣는다) →
피사 교역소 「고맙소！ 보수는 튀니스항에서 받으시오」(E3 로 내린다) → 튀니스 교역소 「보수를 받으시오」 돈 +1000, 장 0.
글의 `$rNN` · `$dNN`(`0x0043E1D0`), 넣기 받을 곳 3(포인터 따라가기), 표 19(교역품 이름 포인터), `EE`(빈 짐 자리)가 이 길에 든다.

## 항 「도크」 — 목록 8 (`0x00423990`)

들어가면 `0x00423A90` 이 셈을 차린다. 배 칸 10 ~ 39(서른, 제 함대 0 ~ 9 뒤)에서 +0x1B 가 「지금 항구 | 0x80」 이고 제 함대 갈래(+8 &amp; 0x30 == 0x10)인 것이 이 항구에 맡긴 배다(`0x0049A19C` 척, 번호는 `0x0049A1A4`).
더 맡길 수 있는 척은 맡긴 수에 빈 칸을 더해 다섯까지(`0x0049A1A0`). 머리 말은 0x114(%d척 보관) · 0x115(텅텅) 와 0x116(모두 %d척).

| 것 | 자리 | 셈 |
|---|---|---|
| 보관 | `0x004232F0` | 기함뿐이면 0x117, 다 찼으면 0x120. 배를 고르고(0x118) 선원이 있으면 0x119(%d명 해고), 없으면 0xC9 로 묻는다. 맡기면 0x11A |
| 배비 | `0x004234B0` | 맡긴 배가 없으면 0x11B. 고르고(0x11C) 선장이 될 동료가 없으면 0x11D, 있으면 0x11E |
| 교환 | `0x00423780` | 맡긴 배 하나와 함대의 배 하나를 맞바꾼다(0x11F) |

## 주점 「여급과 대화」 — 목록 13 · 14

여급 표 `SDATA.DAT 0x8BD`, 19바이트 x 30(메모리 `0x0045BB68`, 표 5). +0 이름 13 · +0x0D 나이 · +0x0E 항구 · +0x0F 호감 · +0x12 깃발((>> 4) & 3 취향).
리스본은 카를로타(성의)다.

| 것 | 자리 | 셈 |
|---|---|---|
| 그녀의취향 | `0x00426840` | rand(50) < 호감이면 0x195 + 취향(옷 · 보석 · 성의 · 이야기)을 말하고 호감 += (취향 / 2 + 1) x 2, 아니면 0x193 |
| 그녀의연령 | `0x004268D0` | 호감 > 80 이면 0x194(%d살), 아니면 0x193 |
| 자랑 | `0x00425BE0` | 찾은 발견물(0x20, 0x80 아님)을 골라 그림 · 0x139. 값 = 어려움 / 10 + 1, 취향이 성의 · 무엇이든이면 갈래 맞장구(0x13A ~ 0x140)에 두 배. 항구에 든 뒤 한 번만 오른다(`0x0049F5A4` 0x40) |
| 선물 | `0x00425D70` | 가진 아이템 가운데 갈래 10 · 11(`0x0043CF00`), 없으면 0x14A/0x14B. 0x141, 값 = min(10, 힘). 옷 · 갈래 10(0x142), 보석 · 갈래 11(0x143), 무엇이든(0x144)이면 두 배이고 호감 80 이상이면 0x145. 아이템은 없어진다 |
