# 시나리오 바이트코드 — SNRn.DAT (KOUKAI2.EXE)

옮긴 자리: `Uw2.Support/Local/Formats/Scenario.cs` · 본보기 `StartData.Templates`.

## 파일

`EXE` 의 파일 이름표에 `SNR*.DAT`(바이트코드) · `SNR*.MES`(글) · `SNRDAT.LZW` · `SNRMES.LZW` 가 있다.
`EVENT*.DAT` 는 바이트코드가 아니라 **그림**이다(머리 `NPK016`, 640 x 400, 열여섯 색 12비트 팔레트).

| 파일 | 머리 +5 | 누구 |
|---|---|---|
| SNR0.DAT | 0x80 | 함께 쓰는 것 |
| SNR1 ~ SNR6 | 0 ~ 5 | 사람 번호 — 조안 · 카탈리나 · 옷토 · 에르네스트 · 피에트로 · 알 |

머리는 `"SNDT" 00 id`, `0x12` 부터 4바이트씩 이벤트 첫 자리(앞 두 바이트, 빅엔디언)가 `FFFF FFFF` 까지 이어진다.
SNR1 은 `0x002C · 0x0922 · 0x12A9 · 0x1CF4 · 0x2BBF · 0x2E47`.

## 기계 — 0x0043EFB0

명령 바이트 `0xC0 ~ 0xFF` 를 바이트표 `0x0043F704` 로 손 번호(0~38)에 대고 손표 `0x0043F668` 로 뛴다.
바이트를 꺼내는 손은 `0x0043E170`(짚개 `0x004702BC`).

| 명령 | 손 | 것 |
|---|---|---|
| `E4 v` | 17 · `0x0043F311` → `0x0043DBB0` | 돈 = 변수[v] (60000만에서 자른다) |
| `E6 v` | 18 · `0x0043F33D` → `0x0043DBF0` | 돈 += 변수[v] |
| `E7 v` | 19 → `0x0043DC30` | 돈 -= 변수[v] (0 아래로는 안 간다) |
| `F9 t _` | 32 · `0x0043F55D` | 배 주기 — `0x0043DEA0(t)`. 둘째 바이트는 읽고 버린다 |

나머지 손은 아직 안 갈랐다. 돈은 `0x0049F5A8`(dword, 끝 `0x23C34600` = 6억), 변수는 낱말 판 `0x0049F360`(`0x004702B0`).

### 바이트 갈래 — 0x0043F750

명령 바이트의 위 두 비트로 손을 가른다.

| 위 두 비트 | 손 | 것 |
|---|---|---|
| `00` | `0x0043E830` | 넣기 · 셈 — 비트 5·4 받을 곳 갈래, 3·2 줄 것 갈래, 1·0 셈. `0C v hh ll` = 변수[v] = hhll |
| `01` | `0x0043EB90` | |
| `10` | `0x0043ED90` | |
| `11` | `0x0043EFB0` | 위 명령표 |

### 첫 돈

첫 이벤트에서 `0C v hh ll` 뒤 `E4 v` · `E6 v` 가 붙은 곳:

| 주인공 | 것 |
|---|---|
| 에르네스트 · 피에트로 | 돈 = **5000** |
| 조안 | +1000 두 번 |
| 옷토 | +300 · +10000 |
| 알 | +1000 세 번 · +500 |
| 카탈리나 | 못 찾음 |

더하기가 여러 번인 것은 대사 고르기 갈래로 보인다. 지금은 **첫 것만** 쓴다(`Scenario.FirstGold`) — 조안 1000 · 카탈리나 0 · 옷토 300 · 에르네스트 5000 · 피에트로 5000 · 알 1000. 기계를 다 옮기면 바로잡는다.

## 배 주기 — 0x0043DEA0(선종)

- 빈 배 기록(제 몫 0~39 가운데 `+0x0F == 0xFF`)을 찾아 본보기 `40 + 선종` 의 이름 · 깃발 · 대포 · 선원 자리를 베낀다.
- 빈 함대 칸에 내구 = 선종 내구 x 9/10, 역풍 · 돛 = 선종 값, **선원 0**, 깃발 0x20 으로 넣는다.
- 짐 자리 = 짐칸 - 대포 - 선원 자리.

## 배 기록 — SDATA.DAT 0x4A62, 22바이트 x 65 (메모리 0x00461560)

| 자리 | 것 |
|---|---|
| +0 | 이름 15바이트 |
| +0x0F | 선종(0xFF 빈 것) |
| +0x10 | 깃발 — 비트 0x10 이 돛만 쓰는 배. 갤리 넷(경갤리 · 플랜더스 갤리 · 베네치안 갤리 · 관선)은 이 비트가 없다 |
| +0x11 | 대포 |
| +0x12 | 선원 자리(낱말) |
| +0x14 | 짐 자리(낱말) |

0~39 는 제 함대 몫(새 게임은 이름 「０」「１」… 빈 것), 40~64 는 선종 본보기 — 이름이 곧 선종 이름이다
(발사 · 한 자 콕 · 다우 · 버스 · 타렛테 · 카라벨 라티나 · 카라벨 레돈다 · 브리간틴 · 나오 · 카락 · 갤리온 · 지벡 · 피네스 ·
슬루프 · 프리게이트 · 바그 · 쉽 · 정크 · 경갤리 · 플랜더스 갤리 · 베네치안 갤리 · 라레아르 · 철갑선 · 안택선 · 관선).

## 주인공 첫 배

첫 이벤트 안의 첫 `F9`:

| 주인공 | 첫 배 |
|---|---|
| 조안 | 카라벨 라티나 |
| 카탈리나 | **갤리온** |
| 옷토 | 카라벨 라티나 (첫 이벤트 뒤쪽에 갤리온을 주는 `F9` 가 하나 더 있다) |
| 에르네스트 · 피에트로 · 알 | 카라벨 라티나 |

세이브(`KOUKAI2.DAT`, 0x97 머리 + 0x837B x 10)로 맞춰 보았다 — 1522년 8월 조안의 배 「헤르메스Ⅱ세」가 카라벨 라티나다.
세이브 한 칸은 SDATA 와 같은 자리를 쓴다(머리 해 · 달 · 날, 함대 표 0x247B, 배 기록 0x4A62).

## 남은 것

- 선원 0 으로 받는다 — 우리는 아직 주점이 없어 선원을 채워 띄운다.
- 배 이름 — 지금은 본보기(선종 이름)를 그대로 쓴다. 「헤르메스Ⅱ세」 같은 이름은 다른 명령이 붙인다.
- 나머지 명령.

## 명령 길이 — 손이 이벤트 자리 `0x004702B8` 를 미는 값

손마다 일을 마치면 `0x004702B8 += 길이` 를 하고 `0x0043E1B0` 이 꺼낼 자리를 `바탕 + 0x004702B8` 로 다시 맞춘다. 그래서 길이를 손에서 그대로 읽을 수 있다.

| 갈래 | 길이 |
|---|---|
| `00xxxxxx` 넣기 · 셈 | 3. 셈이 넣기(비트 1·0 = 0)이고 줄 것이 바로 값(비트 3·2 = 3)이며 받을 곳이 2 가 아니면 4 (`0C v hh ll`) |
| `01xxxxxx` | 3 |
| `10xxxxxx` 견주어 뛰기 | 5 — 맞으면 다음 명령, 아니면 끝 두 바이트(빅엔디언) 자리로. 받을 곳 갈래가 2 면 4 |
| 1 | `C3 C4 C7 F0 F1 F2 F8 FF` |
| 2 | `C0 C5 CA CD D1 E4 E6 E7 E8 E9 EA EC ED EE F4 FB` |
| 3 | `C8 CC D4 E2 E3 F9 FC FE`(`FE hh ll` = 그 자리로 뛰기) |
| 4 | `C9 EB FA` |
| 5 | `D0 DC` |
| 6 | `CB` |

`uw2 snr <SNRn.DAT> [이벤트]` 가 이것으로 이벤트를 늘어놓는다. SNR1~3 첫 이벤트는 모르는 바이트 없이 끝까지 읽히고,
SNR4~6 은 한두 바이트(`D2 · D3 · DD` — 손이 없는 명령)가 남는다. 대사는 `C0 n`(누가) · `CC 00 k` · `C8 00 m`(말 m) · `C7`(기다림)
꼴로 되풀이되는 것으로 보인다 — 아직 굳히지 않았다.

## 장 · 절 · 방아쇠 — 0x0043E5A0 · 0x0043F8C0

```
장 E  = SNRn.DAT 0x10 + 장(0x004702A4) x 4 의 빅엔디언 dword
절 S  = E + [E + 절(0x004702A8) x 2] 의 낱말 — S 에서 0x4000 바이트를 담개(0x00470238)에 올린다
방아쇠 = S 맨 앞, [항구][건물][자리 hh ll] 넷씩, 항구 0xFF 로 끝
         항구 0xA3 은 0x82 아래 아무 항구, 건물 0xFF 는 아무 건물. 맞으면 S + 자리 로 뛴다
뛰기 · 견주어 뛰기의 자리도 모두 S 에서 잰다
```

건물에 들면(`0x00431FD9`) 이 표를 먼저 본다. 조안 1장 0절은 모두 리스본(항구 0) — NPC(조안의 집) · 주점 · 왕궁 · 교회 ·
조선소 · 항 · 교역소 · ITEM, 그리고 아무 건물(0xFF).

조안의 집에 처음 들면(깃발 0 이 꺼져 있으면) 아버지 레온 페레로 공작이 프레스터 존왕국 탐험을 명하고
「네가 탈 배는 조선소에 부탁해 두겠으니」 뒤에 `F9 05`(카라벨 라티나)를 준다. 이벤트는 `F8 F2` 로 끝난다.

## 연산 갈래(넣기 · 견주기의 받을 곳 · 줄 것) — 0x0043E6E0

| 갈래 | 것 |
|---|---|
| 0 | 낱말 변수 `0x0049F360[i]` |
| 1 | 게임 기억 가리키개 `0x0049F260[i]`(dword) — `D0 · DC` 가 놓는다(아래) |
| 2 | 깃발 비트 `0x0049F3E0` 의 i 번째 |
| 3 | 바로 값 |

깃발은 줄 것으로 읽으면 0xFFFF(바이트면 0xFF)다.

### 세 갈래 바이트 — 예전 풀이를 고친다

처음에는 `00` 갈래의 끝 두 비트를 「넣기 · 더하기 · 빼기」로 읽었는데 틀렸다. 끝 두 비트는 **폭**이고 셈은 `01` 갈래다.

| 갈래 | 꼴 | 뜻 |
|---|---|---|
| `00 DD SS WW a b` | 넣기 `0x0043E830` | 갈래 S 의 b 를 갈래 D 의 a 에. W 0 낱말 · 1 바이트(낮은 바이트) · 2 오류 · 3 게임 값 여덟(b 0~7, 아직) |
| `01 O B SS oo a b` | 셈 `0x0043EB90` | B 0 → 변수 a(낱말), B 1 → 가리키개 a 자리(바이트). `O·oo`: 0 + · 1 − · 2 × · 3 ÷(0 이면 0xFFFF) · 0x20 or · 0x21 and · 0x22 가리키개 a 를 b 만큼 앞으로 · 0x23 뒤로 |
| `10 AA BB cc a b t` | 견주기 `0x0043ED90` | 낱말(부호 없이) A ? B. cc 0 같다 · 1 다르다 · **2 A ≥ B · 3 B ≥ A** |

견주기도 예전에는 2 · 3 을 거꾸로 읽었다(`sbb esi, esi; inc esi` 가 「A &lt; B 가 아니다」). 맞으면 다음 명령, 아니면 절 바탕 + t 로 뛴다.
앞이 깃발이면 뒤는 깃발이거나 바로 값이어야 한다(아니면 오류) — 깃발 · 깃발은 같은지, 깃발 · 값은 `cc & 1` 과 같은지.

### 가리키개 — D0 · DC (`0x0043D510`)

`D0 p t r f` · `DC p t r f` 가 가리키개 p 에 「표 t 의 r 번 기록 f 바이트」를 놓는다. D0 은 r 을 변수 r 의 낮은 바이트에서 읽는다.
SNR0~6 에서 D0 은 395번, DC 는 491번 나오고 표 1 · 2 · 3 · 4 · 8 이 많다. 갈래 1 을 쓰는 넣기 · 견주기는 1,481번이다.

| 명령 | 뜻 |
|---|---|
| `C0 n` | 대사 창 n(창 표 `0x0045E348`, 24바이트씩) — 1 위 · 2 아래 · 0 · 3 넓은 창. 한꺼번에 둘까지 연다 |

## 글 — SNRn.MES

머리가 글 자리(빅엔디언 4바이트)들, 첫 자리 / 4 가 글 수(조안 1172). `§이름§` 이 말하는 사람, `/` 가 줄 바꿈,
`$n` · `$s` 가 이름 · 성, `(이냐)` · `(야)` 따위가 받침 따라 고르는 토씨다(`ScenarioText`).

## 옮긴 것 — ScenarioVm

넣기 · 셈, 견주어 뛰기, 뛰기, 대사(C8 · D4), 배 주기, 돈, 그침, 다음 절(`F0` → 끝난 뒤 절 + 1) · 다음 장(`F1` → 장 + 1,
절 0, 깃발 앞 서른둘을 지운다 — `0x0043F7BA`). 깃발 · 변수는 주인공 시나리오와 함께 남아 있어, 조안이 집에 두 번째 들면
깃발 0 이 서 있어 집사가 「들이지 말라는 공작님의 분부」로 막는다. 대사 창 · 얼굴 · 고르기 · 가리키개도 옮겼다. 나머지 명령은 길이만큼 넘긴다. 첫 배는 새 게임 때 바로 주고(조안이 집에 가기 전에도 배가 있다),
시나리오가 같은 선종을 또 주면 넘긴다.

### 이벤트 다음 건물 목록 — `0x00431FF9`

이벤트 손(`0x0043F830` · `0x0043F9F0`)이 돌려주는 값은 기계 고리(`0x0043F750`)가 1 로 두고 손마다 넘기는 값이다.
그것을 0 으로 만드는 것은 **`F8`**(`0x0043F53F`) 하나다. 그침 `F2`(`0x0043F652`)는 고리만 멈추고(손의 ebp 를 0 으로), `FF` 는 아무 일도 하지 않는다
(예전에는 F2 가 0 을, FF 가 끝을 뜻한다고 잘못 읽었다).
함께 쓰는 시나리오(SNR0)와 주인공 시나리오 둘 다 1 이면 건물 목록이 뜨고, 하나라도 0 이면 목록 없이 나온다 — 여관(건물 4)만은 늘 뜬다.
조안 집의 아버지 장면은 `F8 F2` 라 거기서 끝나고, 리스본 여관의 「참 신세를 많이 지고 있습니다」 인사는 목록으로 이어진다.

### 더 옮긴 명령

| 명령 | 손 | 뜻 |
|---|---|---|
| `E9 f` | `0x0043DCE0` | 예 · 아니오(`0x004385B0`) → 깃발 f 를 세우거나 지운다 |
| `EA v` | `0x0043DD50` | 변수 v = 돈 / 10000 |
| `EB v hh ll` | `0x0043DD80` | 변수 v = 주사위(hhll). 씨앗 = 씨앗 x 0x5D588B65 + 1, 값 = (씨앗 >> 8 & 0x7FFF) % hhll |
| `EC v` · `ED v` | `0x0043DDE0` · `0x0043DE00` | 씨앗 = 변수 v << 8 · 변수 v = 씨앗 >> 8 |
| `EE v` | `0x0043DE20` | 변수 v = 우리 배들의 빈 짐 자리 합(배 기록 +0x14 − 짐) |
| `FB p` | `0x0043E0D0` | 사람 p 가 동료로 — 빈 동료 칸에, 처지 6, 함대 · 머무는 곳은 주인공 것 |

씨앗은 이벤트를 열 때 `((주인공 +0x26 낱말 + 항해 레벨) x 해 x 달 + 날 + 시각) << 8` 이다(`0x0043F9F0`).
FB 로 드는 이는 조안의 로코 알렘켈(69) · 엔리코 마리오네(70) · 도밍고 마나나(71), 카탈리나의 프랑코 사누드(72) · 안드레아 기지(73),
옷토의 마슈 로이(75), 에르네스트의 로이드 스탓텐(77), 피에트로의 카미로 스테파노(76), 알의 자한 사림(78) · 옷토 스피노라(2)다.

화면 몫이라 넘기는 것: `C7` 기다림(4202번) · `F8`(314) · `C4` 창 닫기(142) · `CA` 연출(124) · `CB` 그림 · `D1` 함대 보기.
`E2 g a` 는 변수 g 교역품을 변수 a 만큼 값 없이 싣고(넘치면 버린다, `0x0043D980`), `E3 g a` 는 그 교역품을 다 내려 내린 양을 변수 a 에 넣는다(`0x0043DAB0`).
`FC m n` 은 여급 m 의 호감(표 5 +0x0F)에 n 을 더한다, 100 까지(`0x0043E140`).
`E8 p` 는 사람 p 의 신상 장면(`0x0043DC70`)이다 — 우리는 이름과 레벨 · 능력치를 대사 한 줄로 보인다.
`FA t hhll` 은 바로 앞 `F9 t` 로 받은 배에 글 hhll 을 이름으로 붙인다(`0x0043E1D0` 이 글을 펴고 `0x0043E000` 이 그 칸을 제 배로 돌린다) — 조안의 「헤르메스Ⅱ세」(SNR1 글 0x84).

## 자리 표 0xA0 ~ 0xA3

이벤트 머리의 항구 칸은 항구 번호 말고도 넷을 더 쓴다(맞추기 `0x0043FB15` — 같은 자리, 또는 항구 번호가 100 아래이고 칸이 0xA3).

| 칸 | 뜻 | 부르는 곳 |
|---|---|---|
| 0xA0 | 바다 — 건물 칸이 바다에 나온 날 수(`0x0045BDA8`) | 바다 고리 `0x00418D45` |
| 0xA1 | 싸움 쪽 | `0x0040FB31` |
| 0xA2 | 싸움 쪽 | `0x0040ABB7` |
| 0xA3 | 어느 항구든 | |

조안은 아버지를 뵌 뒤(장 0 · 절 1) 바다 사흘째에 밀항자를 만나 「마냐나」 라는 성을 지어 준다.
