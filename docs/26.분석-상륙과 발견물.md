# 상륙과 발견물

바다 명령 「상륙」(목록 29) 과 발견물 백 — `KOUKAI2.EXE` 자리.

## 발견물 표

`SDATA.DAT 0x5D86`, 7바이트 x 100(98 개를 쓴다). 메모리 `0x00460620`, 시나리오 기억 표 16. 한 줄을 가리키는 손은 `0x0043AF50(번호)` 다.

| 자리 | 크기 | 뜻 |
|---|---|---|
| +0 | 2 | x — 칩 눈금(항구 표 · 함대와 같은 자). 스톤 헨지가 168 이고 런던이 180 이다 |
| +2 | 2 | y — 스톤 헨지 270, 런던 262 |
| +4 | 1 | 묶인 아이템 — 새 게임이 0x5A + k 로 적는다 |
| +5 | 1 | 어려움 |
| +6 | 1 | 깃발 — &7 갈래, 0x10 물 탐색에 쓴 것, 0x20 찾았다, 0x80 이번 게임에는 없다 |

갈래 이름은 `0x00457560`(han8 같은 자리), 7바이트씩: 보물 · 원주민 · 동물 · 식물 · 유적 · 괴물 · 자연 · 원주민.

이름 · 풀이는 `COLONY.DAT`(`0x0045765C` 가 「c:COLONY.DAT」) 177바이트 x 100 — +0 이름 15 · +15 한 바이트 · +16 풀이(끝 0). `0x0041AB30` 이 읽는다.

## 새 게임 (`0x00416AE0`)

```
98 개 모두 +6 |= 0x80
쉰 번: i = rand(98); 0x80 이 서 있으면 풀고 센다
열 번: i = rand(98); 아직 0x80 이고 +4 < 0x5A 이면 +4 = 0x5A + k, 아이템 0x50 + k 의 +0x12 = i
```

한 게임에 발견물은 쉰 개다. 남은 것 열 개는 아이템(보물 지도 쪽으로 보인다)에 묶인다 — 아직 안 했다.

## 상륙 (`0x0041AD60`)

방위를 골라 내린 칩을 셈한다(함대 그림 자리 − 0x60 · − 8 을 16 으로 나누고 화면 굴림 `0x0049F038` · `0x0049F034` 를 더한다).
`0x0041AFD0(x, y)` 가 x − dx · y − dy(dx, dy = 0 · 1) 와 같은 발견물을 찾아 `0x004608DA` 에 둔다(없으면 0xFF).
사막 칩(0x59)에 내리면 `0x00458260` = 0 — 물이 없다.

- 발견물이 있고 0x80 이 아니면 「부락에 」(0x1B7) + 「상륙하겠습니다. 좋습니까？」(0x1B8) 뒤 `0x0041BA90`, 목록 35.
- 아니면 0x1B8 뒤 `0x0041B090`, 목록 36(출항 · 응급수리 · 탐색 · 대기).

우리는 방위를 고르지 않고, 함대 둘레에 뭍이 있으면 내리고 둘레 세 칩 안의 발견물을 잡는다(`Discoveries.Near`).

## 부락 — 목록 35

| 것 | 자리 | 셈 |
|---|---|---|
| 보물탐색 | `0x0041BB50` | 식량이 없으면 0x1AC. 찾았던 것이면 0x1B0. 어려움 ≥ 운(+0x23) x 3/20 + 지식(+0x1F) x 7/20 + 덤(`0x0049A164`) 이면 0x1AD. 아니면 찾는다 — 원주민 · 괴물은 습격(0x1AE)과 땅 싸움, 나머지는 0x1AF. +6 \|= 0x20, 그리고 그림 · 풀이 |
| 환대 | `0x0041BD40` | 0x1B1 을 묻고, 식량 20 이 있으면 덜고 덤 += 5(0x1B2). 없으면 0x1B3 |
| 식량약탈 | `0x0041BE00` | 0x1B4 를 묻고 (rand(5) + 2) x 10 을 싣는다(0x1B5). rand(4) == 0 이면 반격(0x1B6 + 땅 싸움). 주인공 +0x22 를 min(2, 값 − 50), 운을 min(2, 운) 만큼 덜고 덤은 0 |
| 출항 | `0x0041B210` | |

땅 싸움 `0x0041ACE0(세기)`: 검술(+0x21) / 2 = c, v = min(100, 전투 레벨 x c / 25 + c), 세기 = (100 − v) / 2.
배마다 선원 x 세기 / 100 이 죽고 그 합을 0x1AB 로 알린다.

## 뭍 「탐색」 — 물 (`0x0041B870` → `0x0041B8B0`)

물을 찾는지(`0x0049A16C`)는 내릴 때 정한다: rand(100) < 운 x `0x00458260`. 사막이면 0x1A8 로 먼저 묻고 늘 못 찾는다(0x1A9).
찾으면 0x1AA 뒤 배를 골라 실을 만큼(0x1A7) 묻는다. 우리는 배마다 빈 자리를 다 채운다.

## 뭍 「응급수리」 (`0x0041B240` → `0x0041B670`)

배를 고르고(다 멀쩡하면 0x1A2) 내구(+2/+3) · 역풍(+4) · 돛(+5) 가운데 하나를 고른다. 함대에 자재가 없으면 0x1A3, 그 곳이 멀쩡하면 0x1A4.
쓸 수 있는 자재는 min(함대 자재, (상한 − 지금 + 4) / 5) 이고(0x1A5), 자재 하나가 5 를 고친다. 상한은 역풍 · 돛이 선종 값, 내구가 배 최대 내구다.
쓴 자재는 앞 배부터 덜어 낸다(`0x0041B810`).

## 아직

- 발견물 그림(KAO 128 + 번호), 아이템 묶음.
- 여급 「자랑」(`0x00425BE0`, 목록 14) — 0x80 이 아니고 0x20 인 것을 늘어놓고 어려움 / 10 + 1 만큼 호감이 오른다(0x139 · 0x13A ~ 0x140).
- 귀족 「모험소문」(`0x00421D10`), 학자(갈래 1, 목록 25 — 기능 습득 · 지리 보고 · 지도확인).

## 귀족 — 「NPC」 건물

임자 표 `SDATA.DAT 0xAF7`, 22바이트 x 20(메모리 `0x0045B9B0`, 표 4). 건물에 들면 `0x0049A190` 이 그 항구의 임자를 가리킨다.

| 자리 | 뜻 |
|---|---|
| +0 | 이름 17 |
| +0x11 | 갈래 — 0 귀족(목록 24) · 1 학자(목록 25) · 0xFF 왕 |
| +0x12 | 얼굴(낱말) |
| +0x14 | &3 집안 격 · 0x10 계약했다 |
| +0x15 | 사는 항구 — 집사 마르코 0(리스본) · 모리스 백작 34 |

`0x00421E90` 은 계약했으면 「오！ %s님」(0x1DE, 주인공 성), 아니면 0x1DD 로 맞고 목록 24(계약 · 발견물 보고 · 모험소문)를 띄운다.

- 계약 `0x00421AA0`: 0x1E0 · 0x1E1 을 묻는다. 하면 갈래 0 모두의 0x10 을 풀고 이 임자에 세운다(0x1E3).
- 발견물 보고 `0x00421B30`: 찾았고 있고 아직 안 판(+6 &amp; 0x10 == 0) 것 — 없으면 0x1E4. 하나를 고르면
  ```
  값  = (5 − 격) x (어려움 == 100 ? 4 : 1) x 어려움 x 50          돈에 더한다(6억까지)
  명성 += min(50000 − 명성, 어려움 x (어려움 == 100 ? 15 : 8))     주인공 표 +4
  말  = 0x1E6 + 어려움 / 25                                          +6 |= 0x10
  ```
