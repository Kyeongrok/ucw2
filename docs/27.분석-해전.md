# 해전 (KOUKAI2.EXE)

바다에서 「공격」 하거나 남 함대가 덮칠 때 열리는 헥스 싸움. 읽은 데까지 적는다.

## 들머리

| `0x0040FAC0` | 판 — 판 깔기(`0x0040FBE0`), 시나리오 이벤트 0xA1 을 두 편 제독으로 물어 막을 수 있다(`0x004715A4` = 8). 만남 목록(`0x00410C80`, 교전 · 도망 · 항복)은 두 편 다 원군이 없을 때만 |

## 네 편

`0x00470F60` 에 16 바이트 x 4 — 0 덮치는 편 · 1 덮치는 편 원군 · 2 맞는 편 · 3 맞는 편 원군(짝수 · 홀수가 적 · 우리다).

| +0x0C | 제독(사람 번호) |
| +0x0D | 배 수 |

## 판

헥스 52 x 48(`0x00470590`, 줄 0x34 바이트). 함대 자리 둘레 6 x 6 칩을 세계 칩 표에서 읽어(칩 < 0x34 면 바다) 칩 하나를
8 x 8 칸으로 편다(`0x0040FCA0`). 뭍 칸 둘레는 반반으로 깎고(`rand(2)`), 이웃 여덟 칸 무늬로 해안 칩(0x85 ~ 0x8C)을 고른다(`0x0040FF20`).

헥스는 홀수 열이 반 칸 내려간 꼴이다. 거리(`0x004112B0`): Y = 2y + (x & 1), dx = |x1 − x2|, dy = |Y1 − Y2|, 거리 = (max(dx, dy) + dx) / 2.

바람(`0x004101C0`): 세기 `rand(8) + 1`(`0x0047159C`), 갈래 `rand(8) x 5 / 7`(0 ~ 5, `0x00471598`). 여섯 방위 값(`0x00471590`)은
바람 갈래에서 1 · 2 · 3 · 4 · 3 · 2.

## 틱 고리 — 0x00411140

시각이 63 틱이 되면 그만(`0x004715A4` = 1, 밤). 틱마다 열 바퀴, 바퀴마다 네 편이 이번 차례 배 하나씩 움직인다 —
제 함대 기함이 아닌 제 배도 남 배처럼 스스로 움직이고(`0x0040A830`), 제 기함만 명령 목록을 받는다(`0x0040D6E0`, 손표 `0x00457B28`).

끝(`0x0040A7A0`): 0 편 기함이 죽으면 `0x004715A4` = 4 + (0 편이 제 함대면 1), 2 편 기함이 죽으면 같은 셈. 빼앗긴 것이면 − 2.

## 포격 — 0x00412570

| 단계 | 셈 |
|---|---|
| 세기(`0x004128A0`) | a = 통솔 x 전투 레벨 / 100 + 통솔 / 2, 문 = min(단 문 / 2, 선원 x 갑판 몫 / 100 / 2), b = 거리 세기 x 문 / 10 → 포술이 있으면 (b + 19) / 20, 없으면 (b + 39) / 40. 세기 = a x b / 100 x (rand(검술 / 2) + 50) / 100, 위끝 rand(전투 레벨 / 2) + 50, 아래끝 1. 주인공 배면 통솔 · 검술 · 전투 레벨 · 포술을 부선장 · 수석항해사(처지 3 · 5)와 견준다 |
| 피해(`0x004126D0`) | 내구 −세기, 선원 −(세기 / 2 + rand(3)). 덤: 세기 &lt; 10 이면 다섯에 넷은 없음, 아니면 rand(19) → 0~3 최대 내구 · 4~7 돛 · 8~11 역풍 · 12~13 최대 내구+돛 · 14~15 최대 내구+역풍 · 16~17 돛+역풍 · 18 셋 다. 세기 20 위면 rand(7) 로 3 · 5 · 6 · 7, 40 위면 셋 다. 최대 내구는 −1(선종 내구 / 4 아래로는 안 감), 돛 · 역풍은 −(rand(3) + 세기 / 2) |
| 끝 | 내구 0 → 가라앉음(`0x004125F0`), 선원 0 → 빈 배가 칸을 막는다(`0x00412640`). 제 배가 쏘면 경험 10, 쓰러뜨리면 최대 내구 x 10. 탄약 −1 |

## 백병 — 0x00412B50

서로 `0x00412CD0` 만큼 선원을 잃는다 — (rand(10) + 선원) x 갑판 몫 / 100 x 백병 세기 / 100 x (rand(검술 / 2) + 50) / 100, 1 ~ 50.
맞은 쪽 선원이 0 이면 빼앗았다. 기함끼리면 일기토를 물을 수 있다(0x302, 받아들이려면 적 선원 ≤ 제 선원 + rand(운), 아니면 0x303).
남 기함은 검술 + rand(15) ≥ 주인공 검술이고 rand(주인공 선원) ≤ 운이면 일기토를 건다. 일기토 손은 `0x00414FC0`(`0x004130E0` · `0x004150C0`) — `Duel` · `DuelWindow` 로 옮겼다.

## 전투 경험 — 0x00412500 → 0x0041A4C0

경험(+0x28 낱말)이 min(레벨, 18)² x 30(`0x0041A490`)을 넘을 때마다 전투 레벨(+0x25)이 오른다(100 이 끝). 한 번이라도 오르면
능력치 0 ~ 3 이 rand(3)씩, 오른 레벨마다 용기(+0x20) +rand(3) · 검술(+0x21) +rand(2).

## 남 배의 생각 — 0x0040A830

1. 버틸 만한지(`0x0040A880`) — 아니면 +0x16 |= 8.
2. 갈 수 있는 칸(`0x004119C0` → `0x00411D20`), 위험 판 `0x00470F54`(`0x00411A80`: 적이 그 칸을 쏠 수 있으면 거리 세기, 이웃이면 백병 세기를 더한다),
   기회 판 `0x00470F50`(`0x00411BC0`: 그 칸 · 뱃머리에서 칠 수 있는 적의 세기 — 대포를 앞세우는 배는 포격 x 2, 아니면 백병 x 2 — 가장 큰 것과 그 뱃머리).
3. 갈래(`0x00457AC8`) — 0/1 위험이 가장 적고 멀리 간 칸(`0x0040A660`), 2/3 과녁(노리는 배, 없으면 적 기함)에 max(거리, 사거리)가 작은 칸(`0x0040A2F0`),
   4/5 제 기함 곁(`0x0040A460`), 6/7 제 기함 따르기, 8 위 물러나기(`0x00409F90`: 가장자리 칸 → 이탈, 아니면 가장자리 열두 자리 쪽).
4. 꺾음이 적은 길(`0x00412050`)로 가고(`0x0040A700`), 기회가 있는 칸이면 친다(`0x00412D60` — 노리는 배 먼저, 대포를 앞세우면 포격부터).

## 만남 — 0x00410C80

주인공이 덮치면 `0x00410CB0`, 남이 덮치면 `0x00410DE0`(교전 · 도망 · 항복, 목록 0x36).
세기는 편마다 함대 (내구 합 + 4) / 5(`0x0042ACA0`, 함대 +0x28) — 덮치는 편 `0x00498AA4` · 맞는 편 `0x00498AA8`.

- 주인공이 덮칠 때: 해적이면 0x32B · 0x32D, 아니면 0x32C. 상선(번호 % 10 이 1 ~ 4)은 맞는 편 x 3/2 &lt; 덮치는 편이면 0x32F(배를 세우겠다) — 받아들이면 싸우지 않고 끝 값 2, 아니면 0x330. 그 밖은 0x32E.
- 남이 덮칠 때: 해적 0x331, 노리는 함대(+0x1B = 3) 0x332, 나라 함대 0x333. 덮치는 편 x 3/2 &lt; 맞는 편이면 0x334 아니면 0x335. 도망은 rand(150) &lt; 운 + 항해 레벨이면 0x336(끝 값 3), 아니면 0x338. 항복은 `Encounter.Surrender`(끝 값 9).
- 싸우기 전(`0x00410B90`): 맞는 편이 20 넘게 세면 동료 배가 달아날 수 있다(0x313 ~ 0x316).

## 옮긴 것

`Battle`(Uw2.Game/Engine/Sea/Battle.cs) · `SeaMapHost.OpenBattle` · `CloseBattle` · `BattleWindow`. 원본은 헥스를 한 칸씩 고르지만 화면은
갈 수 있는 칸을 칠해 두고 누른 칸까지 꺾음이 적은 길로 간다. 남 함대 배의 선종 선원 자리(+0x12)는 배 기록을 아직 안 읽어 처음 선원으로 갈음한다.
원군 · 작전 · ITEM · 일기토 · 노획 · 남이 덮치는 만남 · 판 그림도 옮겼다. 노획 짐은 나누기 창(`0x004477C0`)처럼 배를 고르고 → 실을 것을 고르고 → 양을 넣는다. 닫을 때 남은 것이 있으면 0xD3 을 묻고 버린다. 신호(`0x0040CE60`)는 읽는 데가 없어 안 옮겼다.

## 그림 — HDAT.PUT

`0x0040DC80` 이 `HDAT.PUT`(47,104 바이트)을 통째로 읽는다. 32 x 32 조각, 조각마다 512 바이트(한 바이트에 두 점, 높은 네 비트가 왼쪽).
판 칸은 `(칸 & 0x1F) x 512` 조각을 그리고(`0x0040E070`, 홀수 열은 반 칸 내려 아래 반은 +0x100), 배는 `0x1A00 + (뱃머리 + 6 x 갈래) x 0x400` 의
가림(0 · 0xF) 뒤 배 조각(+0x200)을 그린다(`0x0040DDD0`). 갈래 = (제 함대 배가 아니면 1) + (노 젓는 배면 2). 팔레트는 바다 화면 것.
칸 값: 0 · 1 물결, 0x84 민뭍(조각 4), 0x85 ~ 0x8C 해안(조각 5 ~ 12, `0x0040FF20` 이 이웃 여덟의 바다 무늬로 고른다).
`BattleTiles`(Uw2.Support) · `BattleWindow` 가 판을 한 장으로 구워 절반 크기(칸 16 점)로 판 전체를 보인다 — 원본은 13 x 12 칸 창을 굴린다.
