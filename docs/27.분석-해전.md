# 해전 (KOUKAI2.EXE)

바다에서 「공격」 하거나 남 함대가 덮칠 때 열리는 헥스 싸움. 읽은 데까지 적는다.

## 들머리

| 자리 | 것 |
|---|---|
| `0x00409DC0` | 바다 명령 「공격」 — 시각(`0x004703E4`)이 15 ~ 59 틱이 아니면 말 0x30D(야간). 둘레 함대를 고르고(`0x00409EC0`, 없으면 0x30A), 같은 나라면 0x30E 로 묻는다 |
| `0x00409B70(덮치는 제독, 맞는 제독, 덮치는 편 원군, 맞는 편 원군)` | 싸움 한 판 — `0x0040DC80` 채비 → 원군(`0x00409C30`) → 판(`0x0040FAC0`) → 틱 고리(`0x00411120`) → 뒤끝(`0x0040AA10`) |
| `0x00409C30` | 원군 — 둘레 함대 가운데 함대 번호 % 10 이 5 이상(나라 함대 뒤 반)이고 나라가 같은 쪽 편에 든다. 맞는 편 0x30B · 덮치는 편 0x30C. 주인공이 해적(나라 6)이면 없다 |
| `0x0040FAC0` | 판 — 판 깔기(`0x0040FBE0`), 시나리오 이벤트 0xA1 을 두 편 제독으로 물어 막을 수 있다(`0x004715A4` = 8). 만남 목록(`0x00410C80`, 교전 · 도망 · 항복)은 두 편 다 원군이 없을 때만 |

## 네 편

`0x00470F60` 에 16 바이트 x 4 — 0 덮치는 편 · 1 덮치는 편 원군 · 2 맞는 편 · 3 맞는 편 원군(짝수 · 홀수가 적 · 우리다).

| 자리 | 것 |
|---|---|
| +0 | 기함(배 칸 짚개) — 배 칸은 `+0x10` 으로 잇는다 |
| +4 | 이번 차례 배 |
| +8 | 함대 기록(`0x0043AE20`) |
| +0x0C | 제독(사람 번호) |
| +0x0D | 배 수 |

배 칸은 `0x00470FA0 + 편 x 0x168` 에 0x24 바이트 x 10(`0x00410350`).

| 자리 | 것 |
|---|---|
| +0 | 선장(사람 `0x0043ADC0`). 제 함대는 칸 곁 +0x1B, 남은 제독 |
| +4 | 함대 칸(함대 +0x2B + 9 x i) — +0 선원(낱말) · +2/+3 내구 · +4 역풍 · +5 돛 · +7 배 번호 · +8 대포 갈래(& 7) |
| +8 | 자리 = y x 52 + x (낱말) |
| +0x10 | 다음 배 |
| +0x14 | 뱃머리(0 ~ 5) |
| +0x15 | 움직임 쌓임(0 ~ 100) |
| +0x16 | 갈래 비트 — 아래 넷은 남 배 생각 갈래(`0x00457AC8` 손표). 기함 0x22. 0x40 이면 빼앗겼다 · 0x08 물러남 · 0x10 노 젓는 배 |
| +0x17 | 편 << 4 · 칸 번호, 0x80 제 함대 · 0x40 우리 편 |
| +0x18 | 노 힘(노 젓는 배만) |

배가 살아 있는 것(`0x00411280`): 선원 · 내구가 다 0 이 아니고 +0x16 에 0x40 이 없다.

## 판

헥스 52 x 48(`0x00470590`, 줄 0x34 바이트). 함대 자리 둘레 6 x 6 칩을 세계 칩 표에서 읽어(칩 < 0x34 면 바다) 칩 하나를
8 x 8 칸으로 편다(`0x0040FCA0`). 뭍 칸 둘레는 반반으로 깎고(`rand(2)`), 이웃 여덟 칸 무늬로 해안 칩(0x85 ~ 0x8C)을 고른다(`0x0040FF20`).

헥스는 홀수 열이 반 칸 내려간 꼴이다. 거리(`0x004112B0`): Y = 2y + (x & 1), dx = |x1 − x2|, dy = |Y1 − Y2|, 거리 = (max(dx, dy) + dx) / 2.

바람(`0x004101C0`): 세기 `rand(8) + 1`(`0x0047159C`), 갈래 `rand(8) x 5 / 7`(0 ~ 5, `0x00471598`). 여섯 방위 값(`0x00471590`)은
바람 갈래에서 1 · 2 · 3 · 4 · 3 · 2.

## 틱 고리 — 0x00411140

시각이 63 틱이 되면 그만(`0x004715A4` = 1, 밤). 틱마다 열 바퀴, 바퀴마다 네 편이 이번 차례 배 하나씩 움직인다 —
제 함대 기함이 아닌 제 배도 남 배처럼 스스로 움직이고(`0x0040A830`), 제 기함만 명령 목록을 받는다(`0x0040D6E0`, 손표 `0x00457B28`).

끝(`0x0040A7A0`): 0 편 기함이 죽으면 `0x004715A4` = 4 + (0 편이 제 함대면 1), 2 편 기함이 죽으면 같은 셈. 빼앗긴 것이면 − 2.
