## 바다의 한 틱 — 0x0041A34A

```
0x00418250   남의 함대 모두 한 걸음
0x004487B0   제 함대 한 걸음 (빠르기 셈 + 걸음)
inc [0x004703E4]   하루 안 시각 +1
```

부르는 고리(`0x00418D7D`)가 시각이 72(`0x48`)에 닿을 때까지 돌고, 닿으면 날 넘김 `0x004178C0` 으로 간다.
**하루 = 72틱, 한 시간 = 3틱(20분).** 고리는 틱마다 `0x0043AB60(빠르기 + 1)` 로 **(빠르기+1) x 20 밀리초** 를
기다린다(`timeGetTime` 바쁜 기다림). 시각이 12 의 배수일 때만 바람을 흔든다(`0x00418D95` → `0x00418E80`) — 네 시간마다.

`0x0049F598` 의 맨 윗 비트를 지우고, 보급 · 선원 따위를 셈하는 손들(`0x00417930` · `0x00417CD0` · `0x00417E50`)을 부른다.
