# 날씨 — 폭풍 · 무풍 · 안개 (KOUKAI2.EXE)

옮긴 자리: `Uw2.Game/Engine/Sea/Weather.cs`. 셈의 알맹이는 그 파일 머리 주석에 다 적었다.

## 날씨 바이트 0x0049F598

| 비트 | 것 |
|---|---|
| 0..3 | 갈래 — 1 폭풍 · 2 무풍 · 3 안개 |
| 6 | 조짐(항해사가 알렸다) |
| 7 | 오늘 들이닥쳤다 — 날 넘김이 지운다 |

## 흐름 (네 시간마다, 0x00418F2D)

```
맑음  → 0x00418F80  날씨 바다(바람 바이트 비트 7)이고
                     rand(155) > 운+50, 배들 +0x1D 평균 < rand(5) 이면
                     해류 바이트 비트 6·7 로 갈래:
                       0x40 폭풍  rand(7)+3 >= 풍속 이고 향유로 막은 날(0x0049EFBC)이 0
                       0x80 무풍  rand(6) >= 풍속
                       0xC0 안개  rand(10)==0 && rand(6) >= 풍속
                     → 조짐 (0x00419250, 말 0x154 · 0x158 · 0x15C)
조짐  → 0x004193D0  들이닥침, 말 0x15E + 갈래 x 2 (0x160 폭풍 · 0x162 무풍 · 0x164 안개)
들이닥친 뒤          폭풍: 풍속 7, 배를 친다(0x004194D0) / 무풍: 풍속 0 / 안개: (시야)
걷힘 (오늘 든 게 아니면)
                     폭풍  rand(8)==0 또는 날씨 바다 밖     말 0x168 「겨우 위기를 넘겼습니다」
                     무풍  rand(20)==0 이고 표 풍속 != 0    말 0x16A 「바람, 바람이 붑니다」
                     안개  rand(30)==0 또는 날씨 바다 밖     말 0x16C 「겨우 안개가 걷혔습니다」
```

조짐 말은 그 자리 항해사가 있고 `rand(100) < 항해사 +0x1F` 일 때만 한다. 항해사 `+0x1E` 가 70 아래면
「불길한 예감이 듭니다」(말 +2)로 흐리게 말한다. 말 +1 은 같은 뜻의 다른 말투다(사람 `+0x2F` 비트 8).

## 표에서

달 4(May) 바람 장에서 날씨 바다(비트 7) 칸은 44곳. 해류 장의 갈래 비트는 폭풍 19 · 무풍 9 · 안개 16 칸이다.

## 남은 것

- 배들 `+0x1D`(제 함대 칸 곁 30바이트의 끝 바이트) — 뜻을 못 굳혀 0 으로 둔다.
- 폭풍이 배를 치는 셈 — 배에 내구가 생기면 옮긴다(공식은 `Weather.cs` 주석).
- ~~안개가 시야를 가리는 것, 폭풍에 「키가 안 듣는」 것~~ — 날씨 바이트 `0x0049F598` 을 읽는 데를 다 훑었다(아래 표).
  안개는 발견물 · 항구를 알아보는 「보이는 거리」(`0x00448030`)를 0 으로 해 두 칩 안만 보게 한다(`SeaMapHost.LookAround` 가 옮겼다).
  **뱃머리 · 키를 막는 데는 없다** — 폭풍은 풍속 7 · 배 부서짐 · 소리만이다.

| 읽는 데 | 것 |
|---|---|
| `0x00415A03` · `0x00444DDE` | 폭풍이면 소리 0x10(들일 때 · 바다로 돌아올 때) |
| `0x00417970` ~ `0x00417B9A` · `0x0041FB55` ~ `0x0041FC2E` · `0x0041A57B` | 날씨 셈 · 지우기(위) |
| `0x00417EA0` | 날씨 말 고르기 |
| `0x0041A26A` | 맑을 때만 하루 때 빛깔(`0x0041A390`) |
| `0x0042C5F5` | 맑을 때만 경리주임 급료 말 |
| `0x00433E77` | 폭풍 · 안개면 제 배 그림을 따로 그린다(선종 노 비트 · 함대 +0x1A 방위 — 그림만) |
| `0x00448030` | 안개면 「보이는 거리」 0 |

## 폭풍이 덮칠 때 (`0x004193D0` → `0x004194D0`)

조짐이 날씨가 되면(0x0049F598 의 0x40) 말(0x15E + 2 x 갈래, 여자 동료면 + 1)을 띄우고 폭풍이면 배마다 부순다.

```
부서짐 = min(10, (100 − 선장 항해술 +0x1D) / (항해 레벨 / 5 + 3) + 1) + rand(2)
         배 기록 +0x10 의 0x40 이 없으면 x 5
내구 −= 부서짐 · 돛 · 역풍 −= 부서짐 / 2 · 최대 내구 = max(선종 내구 / 4, 최대 내구 − 1)
```
내구가 0 이면 난파다. 주인공이 탄 배면 끝 깃발 0x18(묘비 0x3F6), 아니면 배를 잃고 0x166(%s호가 난파) · 0x329(%s 는 기적적으로 구조)다.

## 폭풍 조건 바로잡음 · 성스런 향유의 막이

`0x00419210` 은 `rand(7) + 3` 이 풍속(`0x0049F5A0 & 7`)보다 **작으면** 그냥 돌아간다(`jl 0x0041924C`). 그래서 폭풍 조짐은 `rand(7) + 3 >= 풍속` 일 때다 —
무풍(`0x00419360`, `rand(6) >= 풍속`)과 같은 꼴이다. 처음에 거꾸로 옮겼던 것을 바로잡았다.
그다음 `0x0049EFBC` 가 0 이어야 조짐이 선다. 성스런 향유(아이템 0x2A, `0x0041FB90`)를 쓰면 폭풍이든 아니든 이 값을 rand(6) + 10 으로 두고
(`0x0041FBFA`), 하루 끝마다 하나 준다(`0x00417908`). `Weather.StormGuard`.

## 배가 사라진다 — `0x004190B0`

맑을 때의 문턱(날씨 바다 · rand(155) > 운 + 50 · 배들 +0x1D 평균 < rand(5))을 넘고 그 자리 바람 바이트 비트 6 이 서 있으면, 갈래를 고르기 전에
`0x004190B0` 을 부른다(`0x0041905E`). 앞 배부터 주인공이 아닌 선장이 맡은 배마다 rand(100) 이 선장 운(+0x23)보다 크고 선장 얼굴 낱말의 위 두 비트
(+0x1B & 0xC0 — 떠돌이 항해자를 만들 때 `0x0042AE30` 이 세운다)가 서 있으면 그 배와 선장이 사라진다: 동료 칸을 비우고 머문 항구 0xFF,
+0x31 의 항해자 비트 0x20 을 지운다(`0x004191B0`), 배를 뺀다(`0x0043B0F0`). 한 번에 한 척, 말 0x150 · 0x151(+0x2F & 8). `SeaMapHost.OnAdrift`.
