# 날씨 — 폭풍 · 무풍 · 안개 (KOUKAI2.EXE)

옮긴 자리: `Uw2.Game/Engine/Sea/Weather.cs`. 셈의 알맹이는 그 파일 머리 주석에 다 적었다.

## 날씨 바이트 0x0049F598

| 비트 | 것 |
|---|---|
| 0..3 | 갈래 — 1 폭풍 · 2 무풍 · 3 안개 |
| 6 | 조짐(항해사가 알렸다) |
| 7 | 오늘 들이닥쳤다 — 날 넘김이 지운다 |

## 흐름 (네 시간마다, 0x00418F2D)

```
맑음  → 0x00418F80  날씨 바다(바람 바이트 비트 7)이고
                     rand(155) > 운+50, 배들 +0x1D 평균 < rand(5) 이면
                     해류 바이트 비트 6·7 로 갈래:
                       0x40 폭풍  rand(7)+3 < 풍속
                       0x80 무풍  rand(6) >= 풍속
                       0xC0 안개  rand(10)==0 && rand(6) >= 풍속
                     → 조짐 (0x00419250, 말 0x154 · 0x158 · 0x15C)
조짐  → 0x004193D0  들이닥침, 말 0x15E + 갈래 x 2 (0x160 폭풍 · 0x162 무풍 · 0x164 안개)
들이닥친 뒤          폭풍: 풍속 7, 배를 친다(0x004194D0) / 무풍: 풍속 0 / 안개: (시야)
걷힘 (오늘 든 게 아니면)
                     폭풍  rand(8)==0 또는 날씨 바다 밖     말 0x168 「겨우 위기를 넘겼습니다」
                     무풍  rand(20)==0 이고 표 풍속 != 0    말 0x16A 「바람, 바람이 붑니다」
                     안개  rand(30)==0 또는 날씨 바다 밖     말 0x16C 「겨우 안개가 걷혔습니다」
```

조짐 말은 그 자리 항해사가 있고 `rand(100) < 항해사 +0x1F` 일 때만 한다. 항해사 `+0x1E` 가 70 아래면
「불길한 예감이 듭니다」(말 +2)로 흐리게 말한다. 말 +1 은 같은 뜻의 다른 말투다(사람 `+0x2F` 비트 8).

## 표에서

4월 바람 장에서 날씨 바다(비트 7) 칸은 44곳. 해류 장의 갈래 비트는 폭풍 19 · 무풍 9 · 안개 16 칸이다.

## 남은 것

- 배들 `+0x1D`(제 함대 칸 곁 30바이트의 끝 바이트) — 뜻을 못 굳혀 0 으로 둔다.
- 폭풍이 배를 치는 셈 — 배에 내구가 생기면 옮긴다(공식은 `Weather.cs` 주석).
- 안개가 시야를 가리는 것, 폭풍에 「키가 안 듣는」 것 — 아직 안 찾았다.
