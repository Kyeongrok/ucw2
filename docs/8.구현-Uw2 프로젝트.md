## 렌더러

3편 `MapD3DRenderer` 를 그대로 옮겼다 — 정점 버퍼 없이 삼각형 하나로 화면을 덮고,
픽셀 셰이더가 **화면 점 → 칩 → 칩 안 점 → 팔레트** 차례로 짚는다. 텍스처는 넷이다.

| 텍스처 | 꼴 | 것 |
|---|---|---|
| `CellMap` | 2160 x 1080 `R8_UINT` | 칩 번호 |
| `Atlas` | 256 x 256 `R8_UINT` | 칩 그림을 가로 열여섯씩 늘어놓은 것 |
| `Palette` | 256 x 1 BGRA | 열여섯 색을 되풀이해 채운 것 |
| `Flat` | 256 x 1 BGRA | **민색표** — 팔레트를 굳히기 전의 기본 |

`SeaMapRenderer.UseChips` 를 켜면 칩 그림으로, 끄면 칩 번호마다 민색으로 칠한다.
**팔레트를 아직 못 굳혀서 민색이 기본**이다.

창은 `HwndHost` 로 자식 창을 만들고 거기에 DXGI 스왑체인을 건다(3편 `ShipMapHost` 와 같다).
끌어 옮기고 휠로 늘이고 줄인다.

| 키 | 것 |
|---|---|
| `F` | 온 지도 보기 |
| `G` | 격자 |
| `C` | 칩 / 민색 |
| `W` | 세계지도로 |
| `L` | **리스본 항구** |
| 방향키 | 옮기기 |

## 항구 화면

세계지도와 렌더러를 나눠 쓴다 — 칸 텍스처와 칩 아틀라스만 갈아 끼우고(`SetCells`·`SetChips`)
가로로 둘러 감는 것을 끈다(`WrapX`). 항구 고르개에 이름 130개가 뜨고 리스본이 0번이다.

```
SeaMapHost.ShowWorld()      세계지도 2160x1080 · 감음
SeaMapHost.ShowPort(0)      리스본   96x96     · 안 감음
```

## 손도구

```
uw2 list   <폴더>              묶음마다 청크 목록
uw2 unpack <파일.LZW> <낼 곳>  청크를 .bin 으로
uw2 map    <폴더> <낼 곳.bmp>  세계지도를 그림으로
uw2 chips  <파일.LZW> <낼 곳.bmp>
uw2 bake   <폴더> <낼 곳>      world.cells · windcur.bin · world.atlas 굽기
uw2 ports  <폴더>              항구 130곳의 이름·자리·칩 벌
uw2 port   <폴더> <번호> <낼 곳.bmp>
```

## 검산

`uw2 bake` 를 두 판 폴더에 대고 돌렸다.

| | 판 가림 | 칩 담는 꼴 | `world.cells` | `world.atlas` |
|---|---|---|---|---|
| DOS 원판 | `MAIN.EXE` | Planar | 583,200 B | 32,768 B |
| Win95 이식판 | `KOUKAI2.EXE` | Packed4 | 583,200 B | 32,768 B |

두 판의 **아틀라스가 바이트까지 같고**, 파이썬 읽개(`uw2.py`)의 결과와도 같다.

## 까맣게 나오던 것

칩 벌을 못 걸었는데 칩 모드로 두면 셰이더가 텍스처 밖을 짚어 **죄다 색인 0(검정)** 이 된다.
Win95판 `DATA1[11]` 이 49,152바이트인데 32,768 만 찾고 있었던 것이 까닭이었다. 셋을 고쳤다.

- 칩 벌 읽개를 `WorldChips.Load` 로 모으고 **앞 128장만** 쓴다(지도가 쓰는 칩이 다 128 아래다).
- 담는 꼴을 `ChipSheet.Open` 이 가린다.
- 못 걸면 `UseChips` 를 끄고 **민색으로 물러선다.** 상태줄에 까닭이 뜬다.
  빈 아틀라스도 128장 크기로 잡아 텍스처 밖을 안 짚게 했다.
